# ADR-0001：仓库内文档与简短 AI 入口

- 日期：2026-11-06
- 状态：已采纳

## 背景

项目需要支持持续学习和 AI 协作。现有 README 混合启动、开发流程和路线规划；用户要求 AGENTS.md 保持简洁，并用 ADR 保存决策过程。

## 决定

采用仓库内 Markdown：README 提供项目介绍和入口，`docs/` 按项目目标、架构、本地开发、协作发布组织，`docs/adr/` 保存决策。根目录 AGENTS.md 仅保留执行原则和链接，人和 AI 共用详细文档。

个人环境和临时限制保存在被 Git 忽略的 `AGENTS.local.md`，由 AGENTS.md 约定按需读取。项目文档维护通用要求，ADR 记录项目层面的决策。

## 备选方案

- 全部放进 README 或 AGENTS.md：初期集中，但阅读负担和重复维护会随功能增加。
- 单独的文档站点或外部知识库：当前文档量较小，增加发布与同步工作。

## 后果

文档能与代码在同一个 PR 中演进，AI 入口保持短小。新增专题时需维护导航，行为变化时更新对应说明。文档量或发布需求增长后再评估站点生成工具。
