## 维护方式

文档与代码一起评审。README 保留项目介绍和快速入口；操作步骤只在对应指南维护；ADR 记录选择的原因，当前设计在架构文档维护。

现阶段采用仓库内 Markdown。随着功能落地，再添加 API 契约、数据模型、工作区状态机等专题，并在此登记；不提前创建空目录或大篇幅占位文档。文档组织决策见 [ADR-0001](adr/0001-documentation-and-ai-guidance.md)。
